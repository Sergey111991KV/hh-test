# Кратко для руководителя

«Контур» помогает руководителю и исполнителям вести строительные объекты и задачи в одном месте. Руководитель добавляет объект, описывает задачу и назначает сотрудника. Исполнитель входит по приглашению, видит только свои задачи, берёт задачу в работу и отправляет результат на проверку. Руководитель принимает работу или возвращает её с комментарием. Карточка задачи показывает, кто и когда менял статус.

Система использует Supabase для учётных записей и хранения данных. Проверка прав настроена непосредственно в базе: даже если обратиться к ней в обход интерфейса, исполнитель не сможет увидеть чужую задачу, поменять назначение или сам принять свою работу. База также проверяет допустимые шаги по задаче и сохраняет историю так, чтобы её нельзя было изменить через приложение.

Чтобы запустить рабочую версию, администратор создаёт проект Supabase, применяет миграцию из репозитория, заводит руководителя и двух исполнителей, добавляет демо-данные и задаёт адрес проекта в настройках хостинга. Пользователи и пароли создаются отдельно; пароли и закрытые ключи в код не попадают.
