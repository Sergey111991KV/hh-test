# Решения, допущения и границы

## Решения

- Используются два типа профиля: руководитель и исполнитель. Все новые Auth-профили получают роль исполнителя; повышение до руководителя выполняется администратором базы.
- Задача на доработке возвращается в работу назначенному исполнителю. Руководитель может принять или вернуть задачу только из статуса «На проверке».
- Возврат задачи требует непустой комментарий. Комментарий хранится в неизменяемой истории статусов.
- Удаление объекта и задачи мягкое: они пропадают из активных списков, но не стирают историю и связанные данные.
- Создание/изменение задач и смена статуса проходят через SQL-функции. Таблица истории доступна для чтения и не имеет прав изменения через API.
- При прямой установке начальных статусов в seed-скрипте история фиксирует начальное состояние. Последующие пользовательские переходы записываются триггером с автором и временем.
- Интерфейс скрывает недоступные действия, но серверные проверки в PostgreSQL остаются источником полномочий.

## Допущения

- Один объект может иметь много задач; у задачи один назначенный исполнитель.
- У объектов обязательное название и необязательный адрес. У задачи обязательное название; описание может быть пустым.
- Исполнители видят объект, если у них есть хотя бы одна активная назначенная задача в нём.
- В тестовом сценарии используются три вручную созданные учётные записи: один руководитель и два исполнителя.
- Публичная регистрация выключена; восстановление пароля и управление пользователями остаются за руководителем/администратором.

## Не включено в тестовый объём

- Реальный Supabase-проект и учётные записи не создавались, потому что доступов к аккаунту не было.
- Приложение не развёрнуто: нужны права на GitHub и Vercel/Netlify. Ни сервисные ключи, ни демо-пароли не добавлены в исходники.
- Загрузка фотографий и файлов, сроки задач, уведомления, комментарии вне обязательного комментария при возврате и полноценное управление сотрудниками не реализованы.
- Видео не записывалось; вместо него добавлено это краткое письменное объяснение.
